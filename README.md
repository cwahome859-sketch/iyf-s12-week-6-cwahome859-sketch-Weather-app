# 🌦️ Weather Dashboard

## 📌 Project Description

The Weather Dashboard is a web application that allows users to check real-time weather information for different cities. Users can enter a city name and view important weather details such as temperature, humidity, wind speed, and weather conditions.

The project was developed to practice HTML, CSS, and JavaScript while learning how to work with external APIs and manipulate the DOM.

## 🚀 Features

- Search for weather information by city name.
- Display current temperature.
- Show weather conditions (sunny, cloudy, rainy, etc.).
- Display humidity levels.
- Display wind speed.
- Show the city and country.
- Loading indicator while fetching weather information.
- Error messages for invalid city names.
- Responsive design for mobile phones, tablets, and desktops.

## 🛠️ Technologies Used

- **HTML5:** Used to structure the dashboard.
- **CSS3:** Used to style the application and create a responsive layout.
- **JavaScript:** Used to handle user interactions and display weather information dynamically.
- **Weather API:** Used to retrieve real-time weather data.
- **DOM Manipulation:** Used to update HTML elements with information received from the API.
- **Fetch API:** Used to communicate with the weather API.

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/weather-dashboard.git
```

2. Open the project folder in VS Code.

3. Configure your weather API key in the JavaScript file.

4. Open `index.html` using Live Server.

5. Enter a city name in the search bar.

6. Click the search button to view the weather information.

## 😓 Challenges Faced

During the development of this project, I encountered several challenges:

1. **Working with APIs:** Understanding how to connect JavaScript to an external weather API and retrieve weather information was challenging.

2. **Handling Promises:** Learning how to use asynchronous JavaScript, `async` and `await`, to retrieve data without blocking the application.

3. **DOM Manipulation:** Updating different HTML elements dynamically using JavaScript was initially difficult.

4. **Error Handling:** Implementing error messages when users entered invalid city names or when the API request failed required additional practice.

5. **Loading Indicators:** Making sure the loading message appeared while fetching data and disappeared when the request was completed.

6. **Responsive Design:** Ensuring that the dashboard displayed correctly on different screen sizes required adjustments to the CSS.

7. **JavaScript Functions:** Understanding how to separate the application into functions such as `displayWeather()`, `showLoading()`, `hideLoading()`, and `showError()` took practice.
